# 🌌 ANIMON
### Discover. Reveal. Collect.

**ANIMON** is an anime-inspired character card experience that brings the excitement of discovering anime characters into an interactive trading-card interface.

Explore characters, discover their stories and quotes, and experience dramatic card reveals powered by elemental animations and atmospheric sounds.

---

## ✨ Features

- **Anime Character Discovery** – Explore a large character catalogue powered by Jikan Edge.
- **Character Artwork** – Displays character artwork and skips characters without working images.
- **Anime Information** – Shows the anime series associated with each character.
- **Quote Discovery** – Retrieves anime quotes using the Animechan API.
- **Elemental Card Reveals** – Five reveal themes:
  - 🔥 Fire
  - 🌊 Water
  - 🌿 Earth
  - 🌪️ Air
  - ⚡ Lightning
- **Animated Backgrounds** – Atmospheric backgrounds with subtle motion effects.
- **Ambient Audio** – Procedurally generated ambient and reveal sounds.
- **Collectible Card Design** – Rarity levels, character statistics and unique card presentation.
- **Print / PDF** – Print cards or save them as PDF files.

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/animon.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Click **NEW CARD** and discover your next character.

A working internet connection is required for external API requests and character artwork.

---

## 🌐 APIs & Data Sources

ANIMON uses external services:

- **Jikan Edge:** https://jikan.lucashdo.com/docs
- **Animechan:** https://animechan.io/

Character information, artwork and quotes are retrieved from these services. Their availability and usage are subject to their respective terms and limitations.
